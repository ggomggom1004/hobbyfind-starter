# HobbyFind 제품 요구사항 정의서 (PRD)

## 1. 제품 상세 설명
HobbyFind는 사용자가 다양한 취미를 쉽고 편리하게 탐색할 수 있는 웹서비스이다.

- 서비스명: HobbyFind
- 서비스 유형: 웹서비스
- 이용 대상: 취미를 탐색하려는 모든 사용자
- 이용 조건: 로그인 없이 이용 가능
- 핵심 목표: 운동형, 지능형, 예술형으로 구분된 18개의 취미를 탐색하고 원하는 분야를 선택할 수 있도록 지원한다.

## 2. 참고 서비스 및 선정 근거
- Airbnb: 사진 중심의 카드형 레이아웃과 간결한 탐색 메뉴를 참고한다.
- 참고 이유: 사용자가 이미지를 통해 관심 있는 취미를 직관적으로 발견하고 카테고리별로 탐색할 수 있도록 하기 위해서이다.
- 구현 범위: 참고 서비스의 시각적 구성만 활용하며 예약, 결제, 로그인 기능은 구현하지 않는다.

## 3. 핵심 기능 및 사양
### 메인 페이지
- 상단바에 HobbyFind 로고와 운동형, 지능형, 예술형 카테고리 메뉴를 표시한다.
- Hero 영역에 서비스 소개 문구를 표시한다.
- 전체 취미 18개를 카드형 그리드로 표시한다.
- 메인 콘텐츠에서 카테고리별 필터를 선택할 수 있다.
- 상단 카테고리 메뉴를 클릭하면 해당 전용 페이지로 이동한다.

### 카테고리별 페이지
- 운동형, 지능형, 예술형 전용 페이지를 각각 제공한다.
- 페이지 상단에 선택한 카테고리명과 소개 문구를 표시한다.
- 해당 카테고리의 취미 카드 6개를 그리드 형식으로 표시한다.

### 취미 목록
- 운동형: 조깅/러닝, 요가, 수영, 자전거, 클라이밍, 댄스
- 지능형: 독서, 퍼즐, 체스, 프로그래밍, 외국어 학습, 사진 촬영
- 예술형: 그림 그리기, 악기 연주, 요리, 서예, 도자기 만들기, 정원 가꾸기

## 4. 사용자 페르소나 및 시나리오
### 페르소나
- 이름: 김하늘(가상 사용자)
- 연령: 30대
- 특징: 새로운 취미를 찾고 싶지만 어떤 활동을 선택할지 고민한다.
- 목표: 관심 분야별 취미를 한눈에 살펴보고 선택한다.

### 이용 시나리오
1. 사용자가 HobbyFind 메인 페이지에 접속한다.
2. 전체 취미 목록을 확인한다.
3. 상단에서 운동형 카테고리를 클릭한다.
4. 운동형 전용 페이지에서 조깅, 요가 등 6개 취미를 확인한다.
5. 메인 화면으로 돌아와 다른 카테고리를 탐색한다.

## 5. 기술 스택 추천
- Next.js: 웹페이지 구성과 페이지 이동 구현
- React: 재사용 가능한 화면 구성요소 개발
- TypeScript: 코드 작성 및 데이터 구조 관리
- Tailwind CSS: 색상, 간격, 배치 및 반응형 디자인
- 정적 데이터: 18개 취미의 이름, 카테고리, 소개 및 이미지 경로 관리

## 6. 제한사항
- 로그인 및 회원가입 기능은 구현하지 않는다.
- 예약, 결제, 댓글 기능은 구현하지 않는다.
- 취미 목록은 지정된 18개로 제한한다.
- 메인 페이지와 3개 카테고리 페이지를 기본 구현 범위로 한다.
- 별도 백엔드나 데이터베이스 없이 구현한다.
- 가이드에서 지정하지 않은 추가 기능은 기본 구현 범위에 포함하지 않는다.
