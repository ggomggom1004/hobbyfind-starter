# HobbyFind 정보 구조 설계서 (IA)

## 1. 서비스 개요
- 서비스명: HobbyFind
- 서비스 유형: 웹서비스
- 이용 조건: 로그인 없이 모든 주요 기능 이용 가능
- 목적: 사용자가 운동형, 지능형, 예술형으로 구분된 취미를 탐색하도록 지원
- 기술 기반: Next.js

## 2. 전체 사이트맵
HobbyFind
├── 메인 페이지 (/)
├── 운동형 페이지 (/category/exercise)
├── 지능형 페이지 (/category/intellectual)
└── 예술형 페이지 (/category/artistic)

## 3. 사용자 흐름 (User Flow)
1. 사용자가 메인 페이지에 접속한다.
2. 전체 취미 18개의 카드를 확인한다.
3. 원하는 카테고리를 선택한다.
4. 해당 카테고리 전용 페이지로 이동한다.
5. 선택한 카테고리의 취미 6개를 확인한다.
6. 로고 또는 메뉴를 통해 다른 페이지로 이동한다.

## 4. 페이지 간 이동 및 내비게이션
- 로고 클릭: 메인 페이지로 이동
- 운동형 메뉴 클릭: 운동형 전용 페이지로 이동
- 지능형 메뉴 클릭: 지능형 전용 페이지로 이동
- 예술형 메뉴 클릭: 예술형 전용 페이지로 이동
- 각 카테고리 페이지에서도 동일한 상단 메뉴를 제공한다.

## 5. 페이지 계층 구조
- 1단계: 메인 페이지
- 2단계: 운동형, 지능형, 예술형 카테고리 페이지
- 각 카테고리 페이지는 메인 페이지의 하위 탐색 페이지로 구성한다.

## 6. 페이지별 주요 콘텐츠 구성
### 메인 페이지
- 상단바: 로고, 카테고리 메뉴
- Hero: 서비스 소개 문구
- 메인 콘텐츠: 전체 취미 카드 18개, 카테고리 필터
- 푸터: 필요 시 기본 안내 문구 및 홈 링크

### 운동형 페이지
- 운동형 제목 및 소개
- 조깅/러닝, 요가, 수영, 자전거, 클라이밍, 댄스 카드

### 지능형 페이지
- 지능형 제목 및 소개
- 독서, 퍼즐, 체스, 프로그래밍, 외국어 학습, 사진 촬영 카드

### 예술형 페이지
- 예술형 제목 및 소개
- 그림 그리기, 악기 연주, 요리, 서예, 도자기 만들기, 정원 가꾸기 카드

## 7. 상호작용 패턴
- 카테고리 메뉴 클릭 시 해당 전용 페이지로 이동한다.
- 메인 화면의 필터 클릭 시 해당 카테고리 카드만 표시한다.
- 활성화된 메뉴와 필터는 시각적으로 구분한다.
- 버튼과 메뉴에 마우스를 올리면 시각적 피드백을 제공한다.
- 반응형 화면에서 카드의 열 수가 자동으로 변경된다.

## 8. URL 구조
| 페이지 | URL |
|---|---|
| 메인 | / |
| 운동형 | /category/exercise |
| 지능형 | /category/intellectual |
| 예술형 | /category/artistic |

## 9. 컴포넌트 계층 구조
- RootLayout
  - Header
    - Logo
    - CategoryNavigation
  - Main
    - HeroSection
    - CategoryFilter
    - HobbyGrid
      - HobbyCard
  - Footer (선택)

공통 Header와 HobbyCard를 재사용하며 페이지마다 필요한 데이터만 변경한다.

## 10. 기술 스택 및 구현 고려사항
- Next.js App Router로 페이지 라우팅 구현
- React 컴포넌트 기반 화면 구성
- TypeScript로 취미 데이터 관리
- Tailwind CSS로 반응형 레이아웃 구현
- 18개 취미 목록은 정적 데이터로 관리
- 로그인 및 데이터베이스 없이 이용 가능
