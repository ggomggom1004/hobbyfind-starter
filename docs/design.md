# HobbyFind 디자인 가이드

## 1. 디자인 시스템 개요
- 서비스명: HobbyFind
- 참고 디자인: Airbnb의 간결하고 직관적인 카드형 디자인
- 브랜드 이미지: 친근함, 밝음, 편안함, 탐색의 즐거움
- 핵심 원칙: 단순한 메뉴, 시각적으로 구분되는 취미 카드, 충분한 여백, 쉬운 탐색
- 디자인 톤앤매너: 밝은 배경, 부드러운 모서리, 선명한 포인트 색상
- UI 키 비주얼: 취미별 사진을 중심으로 구성하고 텍스트는 간결하게 표시한다.

## 3. 페이지 구현 가이드
### 메인 페이지
- 상단바에 로고와 3개 카테고리 메뉴를 배치한다.
- Hero 영역에 "당신만의 특별한 취미를 찾아보세요"라는 문구를 크게 표시한다.
- Hero 영역 아래에 전체 취미 18개를 카드 형태로 배치한다.
- 카테고리 필터는 전체, 운동형, 지능형, 예술형으로 구성한다.
- 각 취미 카드는 이미지, 이름, 카테고리, 짧은 소개로 구성한다.

### 카테고리별 페이지
- 운동형, 지능형, 예술형 각각 별도의 페이지를 제공한다.
- 페이지 상단에 카테고리명과 간단한 소개를 배치한다.
- 해당 카테고리에 포함된 취미 6개만 카드 형태로 배치한다.
- 상단바와 카드 디자인은 메인 페이지와 동일하게 유지한다.

## 4. 레이아웃 컴포넌트
### Header
- 왼쪽에 HobbyFind 로고를 배치한다.
- 오른쪽에 운동형, 지능형, 예술형 메뉴를 배치한다.
- 화면 크기에 따라 메뉴 간격을 조정한다.

### HeroSection
- 넓은 여백과 중앙 정렬을 사용한다.
- 핵심 문구와 설명 문구를 구분한다.
- 배경은 흰색 또는 매우 밝은 핑크를 사용한다.

### HobbyGrid
- 데스크톱은 한 줄에 3~4개 카드를 표시한다.
- 태블릿은 한 줄에 2개 카드를 표시한다.
- 모바일은 한 줄에 1개 카드를 표시한다.
- 카드 사이에는 일정한 간격을 유지한다.

### HobbyCard
- 상단에 취미 대표 이미지를 표시한다.
- 하단에 취미 이름, 카테고리, 짧은 설명을 표시한다.
- 이미지 비율과 카드 높이를 통일한다.
- 카드 모서리는 둥글게 표현한다.

### Footer
- 필요할 경우 간단한 서비스 안내와 홈 링크를 표시한다.

## 5. 상호작용 패턴
- 카테고리 메뉴를 클릭하면 해당 전용 페이지로 이동한다.
- 메인 페이지에서 필터를 선택하면 해당 취미 카드만 표시된다.
- 현재 선택된 카테고리에는 브랜드 색상을 적용한다.
- 버튼에 마우스를 올리면 색상이 자연스럽게 변한다.
- 취미 카드에 마우스를 올리면 그림자나 약한 확대 효과를 적용한다.
- 페이지 등장 시 자연스러운 페이드인 효과를 사용할 수 있다.
- 과도한 애니메이션은 사용하지 않는다.
- 키보드로 탐색할 수 있도록 메뉴와 버튼의 포커스를 표시한다.

## 6. 반응형 브레이크포인트
| 구분 | 화면 너비 | 레이아웃 |
|---|---|---|
| 기본 | 640px 미만 | 카드 1열 |
| sm | 640px 이상 | 카드 1~2열 |
| md | 768px 이상 | 카드 2열 |
| lg | 1024px 이상 | 카드 3열 |
| xl | 1280px 이상 | 카드 4열 |
| 2xl | 1536px 이상 | 넓은 화면에서 콘텐츠 최대 너비 유지 |

### Tailwind CSS 반응형 예시
- 카드 그리드: grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-6
- 메인 컨테이너: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- 제목: text-3xl md:text-5xl font-bold

## 7. 사용자 경험 및 접근성
- 글자와 배경의 명도 대비를 충분히 확보한다.
- 사진을 불러오지 못할 경우 기본 이미지를 표시한다.
- 필요한 경우 로딩 상태와 빈 목록 안내를 표시한다.
- 주요 메뉴는 클릭 가능한 영역을 충분히 확보한다.
- PC와 모바일 모두에서 불편함 없이 사용할 수 있도록 구성한다.

## 8. 개발 시 유의사항
- Next.js, React, TypeScript, Tailwind CSS를 활용한다.
- 기존 프로젝트 구조와 컴포넌트 규칙을 최대한 유지한다.
- 색상과 글씨 및 간격을 일관되게 적용한다.
- 메인 및 카테고리 페이지에서 공통 컴포넌트를 재사용한다.
- 지정된 18개 취미를 중심으로 구성하고 불필요한 기능을 추가하지 않는다.
